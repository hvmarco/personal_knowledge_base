# Geodata Portals Nordic

**Summary**: Where the Swedish, Norwegian and Finnish base data comes from — national mapping agencies, forest and county authorities, heritage and infrastructure registers, and the download services and APIs each of them offers.
**Parent**: [[Data_Sources]] · **Related**: [[QGIS]], [[Terrain_and_Lidar]], [[Solar_and_Weather_Data]]

## Notes

- [NVE Atlas map services (Geocortex REST directory)](https://atlas.nve.no/Geocortex/Essentials/REST/sites/Atlas3/map/mapservices) — the service directory behind NVE Atlas: Norwegian water, watercourse, avalanche, quick-clay and energy layers as REST/WMS endpoints that can be added straight into QGIS rather than browsed in the viewer. Keywords: NVE, Norway, map services, REST, hazard layers. Related: [[QGIS]], [[Permitting_and_Environmental_Assessment]] #type/api #region/norway
- [Skogsstyrelsen geodata feed — SLU markfuktighet klassad](https://geodpags.skogsstyrelsen.se/geodataport/feeds/SLUMarkfuktighetKlassad.xml) — Atom feed for the SLU-modelled soil moisture class raster, downloadable per map sheet. The layer that decides where a site is wet before anyone walks it. Keywords: soil moisture, markfuktighet, SLU, Atom feed, raster. Related: [[Site_Layout_and_Civil_Design]], [[Terrain_and_Lidar]] #type/dataset #region/sweden
- [Instructions for using the API key — National Land Survey of Finland](https://www.maanmittauslaitos.fi/en/rajapinnat/api-avaimen-ohje) — how to obtain and pass an NLS Finland API key for their WMTS, WFS and file download interfaces. Read this before the first Finnish request fails. Keywords: API key, Maanmittauslaitos, WMTS, WFS, access. Related: [[QGIS]] #type/api #region/finland
- [Beta Karttakuva — vector tiles and demos](https://beta-karttakuva.maanmittauslaitos.fi/index.html) — NLS Finland's vector tile service with live demos of the background map styles. Keywords: vector tiles, background map, Finland, NLS. Related: [[Cartography_and_Map_Design]] #type/api #region/finland
- [kartat.kapsi.fi — download of open map materials](https://kartat.kapsi.fi/) — volunteer-run mirror that serves the NLS Finland open datasets as plain downloads and WMTS, without the API key dance. Keywords: Finland, open data mirror, WMTS, download. Related: [[Terrain_and_Lidar]] #type/portal #region/finland
- [Geographical Data for Everyone — GIS Centre, Lund University](https://www.gis.lu.se/gis-centre/geographical-data/geographical-data-everyone) — what Swedish geodata is free to use and under which licence, from the group that negotiates the academic agreements. Keywords: licensing, Swedish geodata, academic access, GIS Centre. Related: [[QGIS]] #type/reference #region/sweden
- [Paikkatietoikkuna](https://kartta.paikkatietoikkuna.fi/?lang=sv) — the Finnish national geoportal map window: every public authority layer in one viewer, with the metadata and service URLs behind each. Keywords: geoportal, Finland, map window, INSPIRE. Related: [[QGIS]] #type/portal #region/finland
- [EPSG.io — coordinate systems worldwide](https://epsg.io/) — CRS lookup with the WKT, PROJ and bounds for each code. The fastest way to settle whether a file is in SWEREF 99 TM, ETRS89 or something older. Keywords: EPSG, coordinate reference system, PROJ, WKT. Related: [[QGIS]], [[Geospatial_Python]] #type/tool
- [Ortofoto nedladdning — Lantmäteriet](https://www.lantmateriet.se/sv/geodata/vara-produkter/produktlista/ortofoto-nedladdning/) — the orthophoto download product: resolutions, coverage years and how it is ordered through Geotorget. Keywords: orthophoto, Lantmäteriet, Geotorget, download. Related: [[Drones_and_Photogrammetry]] #type/portal #region/sweden
- [MapSite — National Land Survey of Finland (e-services)](https://www.maanmittauslaitos.fi/en/e-services/mapsite) — the service page for the NLS map site: what it shows, and the property and terrain data behind it. Keywords: MapSite, NLS Finland, property boundaries, terrain. Related: [[Permitting_and_Environmental_Assessment]] #type/portal #region/finland
- [MapSite (Karttapaikka)](https://asiointi.maanmittauslaitos.fi/karttapaikka/?lang=en) — the map application itself: Finnish base map, aerial imagery, property boundaries and elevation, with coordinate readout. Keywords: Karttapaikka, base map, property, Finland. Related: [[Terrain_and_Lidar]] #type/portal #region/finland
- [Kulturminnesøk — map](https://www.kulturminnesok.no/kart/) — the Norwegian cultural heritage register on a map. The first check for protected monuments and sites in a Norwegian project area. Keywords: cultural heritage, Riksantikvaren, Norway, constraints. Related: [[Permitting_and_Environmental_Assessment]] #type/portal #region/norway
- [Høydedata (LaserInnsyn)](https://hoydedata.no/LaserInnsyn2/) — Norway's national height data portal: lidar point clouds, DTM and DSM by project area, free to download. The Norwegian counterpart to Lantmäteriet's laser data. Keywords: lidar, DTM, DSM, point cloud, Norway. Related: [[Terrain_and_Lidar]] #type/portal #region/norway
- [Vindbrukskollen](https://vbk.lansstyrelsen.se/) — the national register of Swedish wind power projects on a map, permit status included. Useful as a precedent map: where projects were approved, and where they were not. Keywords: wind power, permits, register, Sweden. Related: [[Permitting_and_Environmental_Assessment]], [[Energy_Transition_and_Scenarios]] #type/portal #region/sweden
- [Laserskanning för Nationell Höjdmodell (2009–2019)](https://webgisportal.lantmateriet.se/portal/apps/webappviewer/index.html?id=9586ce671ffe49c1a76e96cfdf453baf) — coverage viewer for the first national laser scanning campaign: which block was flown when, and at what point density. Keywords: laser scanning, national height model, coverage, campaign years. Related: [[Terrain_and_Lidar]] #type/portal #region/sweden
- [Skoglig laserskanning, produktionsstatus](https://webgisportal.lantmateriet.se/portal/apps/webappviewer/index.html?id=36d1e8bd49694da289e2ec7f774f531c) — production status of the ongoing forest laser scanning: what has been flown, processed and released. Keywords: forest laser scanning, production status, Lantmäteriet. Related: [[Terrain_and_Lidar]], [[Swedish_Forestry]] #type/portal #region/sweden
- [FTP — Skogsstyrelsen geodata](https://www.skogsstyrelsen.se/sjalvservice/karttjanster/geodatatjanster/ftp/) — bulk FTP access to the Forest Agency's geodata layers, for when the WMS is too slow to work against. Keywords: FTP, bulk download, Skogsstyrelsen, geodata. Related: [[Swedish_Forestry]] #type/dataset #region/sweden
- [Skogsstyrelsen geodata feed — Lutning (slope)](https://geodpags.skogsstyrelsen.se/geodataport/feeds/Lutning.xml) — Atom feed for the modelled slope raster derived from the national height model, by map sheet. Keywords: slope, lutning, terrain derivative, Atom feed. Related: [[Terrain_and_Lidar]], [[Site_Layout_and_Civil_Design]] #type/dataset #region/sweden
- [Digital soil map of Sweden — clay content (FAO magnifier)](https://gis-slu.maps.arcgis.com/apps/StorytellingSwipe/index.html?appid=e55d28b98d2241e0a6c91ae42073b52f) — SLU's digital soil map presented as a swipe viewer; clay content is the layer that matters for pile driving and trenching. Keywords: soil map, clay content, SLU, geotechnics. Related: [[Site_Layout_and_Civil_Design]] #type/portal #region/sweden
- [Norgeskart](https://www.norgeskart.no/) — Kartverket's national map viewer: topographic base map, property boundaries, place names and elevation for Norway. Keywords: Norgeskart, Kartverket, topographic map, property. Related: [[Terrain_and_Lidar]] #type/portal #region/norway
- [Karta med minimala lufttemperaturer — Boverket](https://www.boverket.se/sv/byggande/regler-for-byggande/om-boverkets-konstruktionsregler-eks/sa-har-anvander-du-eks/karta-med-minimala-temperaturer/) — the design minimum air temperature map that EKS refers to, by municipality. An input to structural and equipment specification, not a climate dataset. Keywords: design temperature, EKS, Boverket, construction rules. Related: [[Site_Layout_and_Civil_Design]], [[PV_in_Nordic_Climates]] #type/regulation #region/sweden
- [Ladda ner geodata — Skogsstyrelsen](https://www.skogsstyrelsen.se/sjalvservice/karttjanster/geodatatjanster/nerladdning-av-geodata/) — the download page for the Forest Agency layers: key habitats, felling notifications, protected areas and the rest, as files or feeds. Keywords: geodata download, nyckelbiotoper, avverkningsanmälningar, Skogsstyrelsen. Related: [[Swedish_Forestry]], [[Permitting_and_Environmental_Assessment]] #type/dataset #region/sweden
- [Skogens Kartor](https://kartor.skogsstyrelsen.se/kartor/) — the Forest Agency's public map viewer, with the same layers in a browsable form. Keywords: forest map viewer, Skogsstyrelsen, key habitats. Related: [[Swedish_Forestry]] #type/portal #region/sweden
- [Geodatatjänster — Skogsstyrelsen](https://www.skogsstyrelsen.se/sjalvservice/karttjanster/geodatatjanster/) — the index of the agency's WMS, WFS and download services, with the service URLs to paste into QGIS. Keywords: WMS, WFS, geodata services, Skogsstyrelsen. Related: [[QGIS]] #type/api #region/sweden
- [Regionala WebbGIS — Länsstyrelserna](https://gis.lansstyrelsen.se/webbgis/regionala-webbgis/) — the county boards' regional WebGIS applications, one per county, holding the local planning and nature layers that never reach the national portals. Keywords: Länsstyrelsen, WebGIS, county data, planning layers. Related: [[Permitting_and_Environmental_Assessment]] #type/portal #region/sweden
- [Länsstyrelsernas Webbgis (standard)](https://ext-geoportal.lansstyrelsen.se/standard/) — the shared county geoportal: protected areas, species observations, cultural environments and shoreline protection in one viewer. Keywords: geoportal, protected areas, strandskydd, county boards. Related: [[Permitting_and_Environmental_Assessment]] #type/portal #region/sweden
- [Geodataportalen — geodata.se](https://www.geodata.se/geodataportalen/) — the Swedish national metadata catalogue: search for a dataset, find who publishes it and how it is served. Keywords: metadata catalogue, INSPIRE, geodata.se, discovery. Related: [[Global_Datasets_and_Catalogs]] #type/portal #region/sweden
- [Öppna dataportalen — Lantmäteriet](https://opendata.lantmateriet.se/) — Lantmäteriet's open data: the free products (topographic base maps, height model derivatives, administrative boundaries) as direct downloads. Keywords: open data, Lantmäteriet, topographic map, boundaries. Related: [[Terrain_and_Lidar]] #type/dataset #region/sweden

- [NVDB på webb](https://nvdb2012.trafikverket.se/setransportnatverket) — the national road database viewer: road ownership, class, bearing capacity and restrictions. What decides whether a transport route to site exists. Keywords: NVDB, road network, bearing capacity, Trafikverket. Related: [[Site_Layout_and_Civil_Design]] #type/portal #region/sweden
