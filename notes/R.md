# R

**Summary**: R and its ecosystem — the tidyverse, ggplot2 graphics, sf for spatial vectors, and the modelling packages (nlme, lme4, emmeans) used for the mixed-model work.
**Parent**: [[Tools_and_Methods]] · **Related**: [[Statistics_and_Data_Analysis]], [[Geospatial]], [[Python]]

## Notes

- **[emmeans: Estimated Marginal Means, aka Least-Squares Means](https://CRAN.R-project.org/package=emmeans)** — Lenth (2021), *CRAN*. Estimated marginal means, contrasts and slope comparisons from fitted linear, generalised linear and mixed models. The package that turns a fitted model into the comparisons a paper actually reports. Keywords: emmeans, estimated marginal means, contrasts, post hoc. Related: [[Statistics_and_Data_Analysis]]. - **[sf: Simple Features for R](https://CRAN.R-project.org/package=sf)** — Pebesma (2021), *CRAN*. Simple features in R: vector data bound to GDAL, GEOS and PROJ, with s2 spherical geometry for lon/lat. The R counterpart to GeoPandas. Keywords: sf, simple features, vector data, GDAL, PROJ. Related: [[Geospatial]], [[Python]]. [zotero](zotero://select/library/items/QZYXEK82) #type/tool
- **[nlme: Linear and Nonlinear Mixed Effects Models](https://CRAN.R-project.org/package=nlme)** — Pinheiro & Bates (2021), *CRAN*. Gaussian linear and nonlinear mixed models, with the variance and correlation structures that lme4 does not offer — the reason it is still the choice for repeated-measures growth data. Keywords: nlme, mixed effects, variance structure, correlation structure. Related: [[Statistics_and_Data_Analysis]]. [zotero](zotero://select/library/items/2XTQXDI6) #type/tool
- **[R: A Language and Environment for Statistical Computing](https://www.R-project.org/)** — R Core Team (2021), *R Foundation*. The canonical citation for R itself. Keywords: R, statistical computing, citation. Related: [[Statistics_and_Data_Analysis]]. [zotero](zotero://select/library/items/PEUAQSAT) #type/tool
- **[ggplot2: Create Elegant Data Visualisations Using the Grammar of Graphics](https://CRAN.R-project.org/package=ggplot2)** — Wickham (2021), *CRAN*. The grammar-of-graphics implementation: map variables to aesthetics and let the package handle the rendering. Keywords: ggplot2, grammar of graphics, aesthetics, visualisation. Related: [[Cartography_and_Map_Design]]. [zotero](zotero://select/library/items/BVR3HJDS) #type/tool
- **[metR: Tools for Easier Analysis of Meteorological Fields](https://CRAN.R-project.org/package=metR)** — Campitelli (2020), *CRAN*. Meteorological fields in the tidy framework, with ggplot2 extensions for scalar and vector fields — contours, streamlines and the analysis functions that go with them. Keywords: metR, meteorological fields, ggplot2 extension, tidy data. Related: [[Solar_and_Weather_Data]]. [zotero](zotero://select/library/items/CKEXNSJX) #type/tool
- **[dplyr: A Grammar of Data Manipulation](https://CRAN.R-project.org/package=dplyr)** — Wickham et al. (2020), *CRAN*. The verb set for data frames — filter, select, mutate, group_by, summarise — in and out of memory. Keywords: dplyr, data manipulation, verbs, tidyverse. Related: [[Statistics_and_Data_Analysis]].
