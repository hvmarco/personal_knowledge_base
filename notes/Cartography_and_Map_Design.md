## Notes

- [AtlasGrid](https://www.styrke10.dk/2025/05/08/atlasgrid-til-dig-der-laver-kortbladsopdelte-atlas-prints-i-qgis/) (for those making map-sheet-divided atlas prints in QGIS) — a QGIS workflow for generating the grid of map sheets an atlas print layout needs. Keywords: AtlasGrid, QGIS, atlas layout, map sheets. Related: [[QGIS]]. #type/tutorial
- [Cartographic Visualization in GIS 2024](https://cartogis.readthedocs.io/en/latest/index.html) — course material on cartographic design principles applied inside a GIS rather than a dedicated design tool. Keywords: cartographic design, GIS, course material, visualization. Related: [[QGIS]]. #type/tool
- [Making Interactive Reveal Maps (QGIS3)](https://www.qgistutorials.com/en/docs/3/interactive_reveal_maps.html) — building a before/after swipe map with QGIS2Web, for comparing two time periods or scenarios in one interactive figure. Keywords: reveal map, swipe map, QGIS2Web, interactive. Related: [[PyQGIS_and_GIS_Automation]]. #type/tutorial
- [Making Interactive Canvas Maps (QGIS3)](https://www.qgistutorials.com/en/docs/3/interactive_canvas_maps.html) — publishing a QGIS project as an interactive web map via QGIS2Web, with popups and layer toggles preserved. Keywords: canvas map, QGIS2Web, interactive web map, publishing. Related: [[PyQGIS_and_GIS_Automation]]. #type/tutorial
- [Enhancing Terrain Cartography with Natural Shadows](https://landscapearchaeology.org/2019/qgis-shadows/) — computing a natural-looking cast-shadow relief layer in QGIS from a DEM, as an alternative to standard hillshading. Keywords: terrain shadows, hillshade alternative, DEM, QGIS. Related: [[QGIS]]. #type/tutorial
- **[Vegetation in Europe](https://commons.wikimedia.org/wiki/File:Vegetation_Europe.png)** — Koistinen (2007), *Wikimedia Commons*. A clean public-domain vegetation-zone map of Europe — the boreal, temperate and Mediterranean bands in one figure, reusable in a report. Keywords: vegetation zones, Europe, thematic map, public domain. Related: [[Climate_Change]], [[Forestry]]. [zotero](zotero://select/library/items/8M9NNFFB) #region/europe #type/reference
- **[ColorBrewer: color advice for maps](https://colorbrewer2.org/#type=diverging&scheme=PuOr&n=4)** — Brewer & Harrower. The sequential, diverging and qualitative colour schemes that most mapping software ships, with colour-blind and print-safe filters. The default answer to "which colours". Keywords: ColorBrewer, colour schemes, diverging, colour-blind safe. Related: [[R]], [[Python]]. [zotero](zotero://select/library/items/WMWXLJFC) #type/tool
